[Judge's field guide and technical report](docs/JUDGES_FIELD_GUIDE.md) · [AWS architecture](docs/AWS-ARCHITECTURE.md) · [Technical README](README-TECHNICAL.md)

## Repository and runtime evidence

Submit **https://github.com/techcto/guardscale**. It is public and includes an
[AGPL license](LICENSE), source, assets, lockfiles, configuration examples and test
instructions. The [CDS evidence table](docs/JUDGES_FIELD_GUIDE.md#runtime-aws-cds-evidence)
links the actual imported and invoked SES/EUM Social APIs and their runtime callers.
A local log-only notification does not count as AWS service use.

## Final checks outside the repository

- Confirm the submission's team, partner eligibility and project-window requirements.
- Supply the qualifying ACE opportunity privately; do not commit its ID.
- Supply the final public/unlisted video URL and verify unauthenticated playback.
- Verify judge account access, free access arrangements and the deployed demonstration.
- Check GitHub recognizes the root LICENSE and that all documentation links open.
- Demonstrate real AWS CDS runtime delivery, the inbound response and agent outcome.
- Describe email receiving and inference according to actual deployment status.

Use the organizer's current [repository instructions](https://github.com/aws-cds-partner/aws-cds-agentic-ai-partner-hackathon-private/blob/main/README.md)
and [competition rules](https://aws-cds-partner.devpost.com/rules) for final eligibility,
access dates and required submission fields. Private-repository access instructions
do not apply to this public repository. Marketplace publication is not required to
show the implemented CDS workflow and no live listing is claimed.
